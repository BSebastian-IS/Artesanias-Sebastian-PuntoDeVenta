# Ambulante y Manzanillo

En Inventario se muestra Existencia 0 y Mínimo 0 solo para Ambulante y Manzanillo. Es una presentación para estas sucursales sin control de stock; no borra las existencias guardadas ni cambia el mínimo compartido de los productos. Ambas sucursales ya venden sin bloqueo ni descuento de inventario en tu Supabase.

Para actualizar en Visual Studio Code, detén el servidor con Ctrl+C y reemplaza src/modules/ventas.js y src/modules/inventario.js con los del ZIP. Conserva tu .env. Ejecuta npm run dev y recarga con Ctrl+Shift+R. No necesitas ejecutar SQL.
