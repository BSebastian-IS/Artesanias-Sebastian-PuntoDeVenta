# Pantalla de acceso y logo

El logo de Artesanías Sebastián se incluye directamente y aparece desde la primera visita, sin iniciar sesión. Se conserva completo y con su proporción original.

Para Visual Studio Code reemplaza src/main.js y src/styles/main.css. Copia también la carpeta public del ZIP a la raíz del proyecto. Conserva .env. Ejecuta npm run dev y recarga con Ctrl+Shift+R. No necesita SQL.
