# Salir sin cerrar sesión
Detén npm run dev con Ctrl+C. Reemplaza src con la carpeta del ZIP, conserva .env y ejecuta npm run dev. Recarga con Ctrl+Shift+R. No requiere SQL ni funciones Edge.
Salir sin cerrar sesión vuelve a Inicio, conserva la cuenta, caja abierta y numeración de tickets. Al entrar de nuevo al punto de venta pide NIP. Si tienes productos sin cobrar, pide confirmar antes de vaciar el carrito. Un cobro pendiente debe confirmarse antes de salir.
Cerrar sesión · Fin del día aparece después del corte. Si tienes cajas propias abiertas, debes hacer sus cortes antes de cerrar sesión. No hace cortes automáticamente.
