# Seguir vendiendo

Inicio muestra un botón adicional Seguir vendiendo en las sucursales donde tu usuario tiene caja abierta. Al pulsarlo confirma tu NIP y regresa al punto de venta con la misma caja y numeración de tickets.

Para Visual Studio Code reemplaza src/modules/inicio.js con el archivo del ZIP. Conserva .env. Recarga con Ctrl+Shift+R. No necesita SQL.
