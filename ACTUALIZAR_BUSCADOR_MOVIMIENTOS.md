# Buscar productos en Entrada / salida

1. Detén el servidor con Ctrl+C.
2. Reemplaza la carpeta src de tu proyecto por la carpeta src de este paquete. Conserva tu .env.
3. Ejecuta npm run dev. No necesitas ejecutar SQL ni publicar funciones.
4. Abre Inventario → Entrada / salida. Escribe el nombre o código en Buscar producto y pulsa Buscar. Selecciona el producto encontrado y completa piezas y motivo.

Filtra mientras escribes, permite Buscar con Enter y Limpiar recupera todos los productos activos. También funciona en Compras → Recibir mercancía. No se guarda un movimiento al pulsar Buscar.
