# Tema azul mar

Para aplicar solo el cambio de colores a tu POS instalado:

1. Extrae este ZIP.
2. Copia `pos-sebastian/src/styles/main.css`.
3. Reemplaza `src/styles/main.css` dentro del proyecto que ya utilizas.
4. Guarda y recarga el navegador. Si no está ejecutándose, usa `npm run dev`.

Este cambio es únicamente visual. No necesitas ejecutar SQL ni publicar funciones otra vez.

Colores: menú azul profundo, botones azul océano, selección turquesa, logo arena, fondo azul muy claro y tarjetas blancas. Se conservan las alertas rojas y amarillas para distinguir errores y avisos.
